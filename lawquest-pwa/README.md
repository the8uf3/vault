# LawQuest — พิชิตข้อสอบกฎหมาย

PWA เกมข้อสอบภาษาไทยจากไฟล์ Markdown ชุดใหม่ทั้ง 6 ไฟล์ รวม 547 ข้อ รองรับตัวเลือก ก.–จ., ถูก–ผิด, PISA หลายตอน, สถานการณ์ร่วมหลายข้อ และข้อเปิดดูเฉลย

## วิธีที่ง่ายที่สุด

ดับเบิลคลิก `LawQuest-เปิดเล่นทันที.html` เพื่อเล่นได้ทันทีโดยไม่ต้องใช้ Terminal ไฟล์นี้รวมตัวเกมและข้อสอบทั้งหมดไว้ในไฟล์เดียว และบันทึกความคืบหน้าด้วยพื้นที่เก็บข้อมูลของเบราว์เซอร์

ไฟล์เปิดทันทีเป็นรุ่นใช้งานในเครื่อง จึงไม่สามารถติดตั้งเป็น PWA ได้ หากต้องการติดตั้งเป็นแอปหรือใช้งานผ่าน Vercel ให้ใช้โปรเจกต์รุ่นด้านล่าง

## เปิดใช้งาน

PWA ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (ไม่ใช่ดับเบิลคลิก `index.html`) เพื่อให้ติดตั้งและใช้ออฟไลน์ได้

```bash
python3 -m http.server 8080
```

จากนั้นเปิด `http://localhost:8080` ใน Chrome, Edge หรือ Safari เมื่อต้องการติดตั้งบนมือถือ ให้นำโฟลเดอร์นี้ขึ้น static hosting ที่ใช้ HTTPS เช่น GitHub Pages หรือ Cloudflare Pages

## ข้อมูลและการตรวจสอบ

- `data/questions.json` ฐานข้อสอบกลาง
- `data/validation-report.json` รายงานจำนวนข้อ/เฉลย/ตัวเลือกแยกไฟล์
- `tools/build_questions.py` ตัวแปลง Markdown ที่ใช้สร้างฐานข้อมูล
- `original/` ไฟล์ Markdown ต้นฉบับทั้ง 6 ไฟล์

ความคืบหน้าและ mastery เก็บใน IndexedDB ของเบราว์เซอร์ ส่วน service worker เก็บตัวเกมและฐานข้อสอบเพื่อใช้ออฟไลน์

หมายเหตุ: ไฟล์ `test-law3.md` ชุดใหม่ข้ามหมายเลขจากข้อ 121 ไปข้อ 123 โดยไม่มีข้อ 122 ในต้นฉบับ ระบบจึงไม่สร้างโจทย์สมมติ และบันทึกช่องว่างนี้ไว้ใน `validation-report.json`
