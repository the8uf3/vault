# ตะลุยข้อสอบครูผู้ช่วย (PWA)

## ไฟล์ในชุดนี้
- `index.html` — หน้าเกมหลัก
- `questions.json` — ข้อสอบทั้งหมด 624 ข้อ (9 ด่าน)
- `manifest.json` — ตั้งค่า PWA
- `sw.js` — Service Worker (offline)
- `icon.svg` — ไอคอนแอป
- `standalone.html` — เวอร์ชันไฟล์เดียว (เปิดได้เลยโดยไม่ต้องมี server)

## วิธี Publish

### 1) Netlify / Vercel / GitHub Pages
อัปโหลดทั้งโฟลเดอร์นี้ (ยกเว้น standalone.html ก็ได้)
เปิดเว็บแล้วติดตั้งเป็นแอปได้

### 2) เซิร์ฟเวอร์ตัวเอง
```bash
# ตัวอย่าง
npx serve .
# หรือ
python3 -m http.server 8080
```

### 3) ใช้ไฟล์เดียว
เปิด `standalone.html` ในเบราว์เซอร์ได้เลย (offline ได้บางส่วน)

## ฟีเจอร์
- 9 ด่านตาม พ.ร.บ. / รัฐธรรมนูญ
- โหมดฝึกซ้อม / จำลองสอบ
- บันทึกคะแนนบนเครื่อง (localStorage)
- ทำต่อจากข้อล่าสุด
- ทบทวนข้อที่เคยตอบผิด
- PWA ติดตั้งบนมือถือได้
