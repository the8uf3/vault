# BodySignal

PWA ส่วนตัวสำหรับติดตามน้ำหนัก รอบเอว การออกกำลังกาย Heart Rate Zones และการฟื้นตัว ข้อมูลทั้งหมดอยู่เฉพาะบนอุปกรณ์ของผู้ใช้

## เริ่มใช้งาน

1. เปิดผ่านเว็บเซิร์ฟเวอร์ HTTPS หรือ localhost
2. เลือก “ติดตั้งแอป” หรือ “เพิ่มไปยังหน้าจอหลัก” จากเบราว์เซอร์
3. หลังเปิดครั้งแรก แอปใช้งานออฟไลน์ได้

แอปจะแสดงข้อมูลตัวอย่างจนกว่าจะบันทึกรายการจริงครั้งแรก ข้อมูลจริงเก็บใน localStorage ของ browser origin นั้นเท่านั้น ไม่มีบัญชีผู้ใช้และไม่มี Supabase

ควรใช้เมนู **ตั้งค่า > สำรองข้อมูล** เป็นระยะ โดยเฉพาะก่อนล้างข้อมูลเบราว์เซอร์ เปลี่ยนเครื่อง หรือถอนการติดตั้ง

## การคำนวณหลัก

- แนวโน้มน้ำหนัก: ค่าเฉลี่ยเคลื่อนที่ 7 รายการล่าสุด
- รอบเอวรายสัปดาห์: median ของ 7 วันล่าสุด
- Training load: Z1×1 + Z2×2 + Z3×3 + Z4×4 + Z5×5
- Baseline load: ภาระเฉลี่ยต่อสัปดาห์จากข้อมูลสูงสุด 28 วัน
- ผลหลังออกกำลังกาย: น้ำหนักวันถัดไปเทียบ baseline ก่อน workout และเริ่มสรุปเมื่อมีอย่างน้อย 5 คู่ข้อมูล

ผลทั้งหมดเป็นการติดตามแนวโน้ม ไม่ใช่การวินิจฉัยทางการแพทย์
