# ตะลุยข้อสอบครูผู้ช่วย (วิชาชีพครู)

## ไฟล์
- `index.html` — หน้าเกมหลัก
- `questions.json` — ข้อสอบทั้งหมด (~450 ข้อ, 5 ด่าน)
- `manifest.json` — ตั้งค่า PWA
- `sw.js` — Service Worker (offline)
- `icon.svg` — ไอคอน

## วิธีใช้
1. เปิดด้วย static server (จำเป็นสำหรับ PWA/fetch):
   ```bash
   npx serve .
   # หรือ
   python3 -m http.server 8080
   ```
2. หรืออัปโหลดทั้งโฟลเดอร์ไป Netlify / Vercel / GitHub Pages

## ฟีเจอร์
- โหมดฝึกซ้อม / จำลองสอบ
- บันทึกคะแนนบนเครื่อง (localStorage)
- ทำต่อจากข้อล่าสุด
- ทบทวนข้อที่เคยตอบผิด
- เลือกแล้วเฉลยทันที
- PWA ติดตั้งบนมือถือได้
